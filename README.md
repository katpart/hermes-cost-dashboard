# Hermes Cost Dashboard

Desktop-плагин для Hermes Desktop: показывает расходы за последние 24 часа, разбивку по провайдерам, курс USD/RUB и лимиты OpenAI/Ollama Cloud.

Плагин рассчитан на standalone-установку из каталога:

```text
%LOCALAPPDATA%\hermes\desktop-plugins\cost-dashboard\plugin.js
```

## Возможности

- Чип **«Расход»** в правой части статус-бара.
- Панель **«Расходы и лимиты»**.
- Раздел **«Расход Hermes и агентов»**.
- Раздел **«Вспомогательные расходы: память и эмбединги»**.
- Расход за последние 24 часа по провайдерам.
- Отдельные итоги в USD и RUB.
- Ручной курс USD/RUB, по умолчанию `90`.
- Для `custom` используется название `provod.ai`.
- Для `unknown` используется название `ProxyAPI`.
- Для OpenAI/Codex с нулевой стоимостью в аналитике выполняется расчёт по тарифу модели; он помечается как расчёт, а не как показание провайдера.
- Для OpenAI динамически показываются:
  - 5-часовой расход и остаток;
  - недельный расход и остаток;
  - время до сброса.
- Для Ollama Cloud показываются сохранённые пользователем значения месячного расхода, лимита, остатка, ориентировочного количества дней и даты сброса.

## Установка на Windows

1. Открой Hermes Desktop.
2. Открой меню управления плагинами и выбери **Reveal/Open plugins folder**.
3. В открывшейся папке создай каталог:

   ```text
   cost-dashboard
   ```

4. Скопируй в него файл `plugin.js` из этого репозитория.
5. В Hermes выполни `Ctrl+K` → **Reload desktop plugins**.
6. В правой части статус-бара появится чип **«Расход»**.

Итоговый путь:

```text
C:\Users\<имя-пользователя>\AppData\Local\hermes\desktop-plugins\cost-dashboard\plugin.js
```

## Как обновить

Скачай новый `plugin.js`, замени старый файл и выполни:

```text
Ctrl+K → Reload desktop plugins
```

Перезапуск Hermes обычно не требуется.

## Источники данных

### Расходы

Плагин читает Hermes Desktop API:

```text
/api/analytics/models?days=1
```

Период — последние 24 часа.

### Лимиты OpenAI

Используется gateway RPC текущей активной сессии:

```text
session.usage
```

Плагин разбирает строки `Session` и `Weekly`, включая формат Hermes:

```text
Session: 88% remaining (12% used) • resets in 2h 26m (...)
Weekly: 74% remaining (26% used) • resets in 5d 4h (...)
```

Результат отображается в формате:

```text
5-часовой: расход 12%, остаток 88%, сброс через 2ч.26мин.
Недельный: расход 26%, остаток 74%, сброс через 5дн.4ч.
```

Если Hermes временно не возвращает данные лимитов, плагин показывает `нет данных`, а не подставляет выдуманное значение.

### Ollama Cloud

Данные Ollama Cloud хранятся в константе `OLLAMA_USER_REPORT` в начале `plugin.js`. Это намеренно ручной источник: после получения новых данных измени значения, замени файл и перезагрузи desktop plugins.

## Настройка курса

В панели используется значение из plugin storage с ключом `usdRub`. Если значение ещё не задано, применяется:

```text
1 USD = 90 RUB
```

Чтобы изменить курс, его можно задать через механизм storage Hermes для плагина `cost-dashboard`. Если в конкретной версии Desktop нет UI для этого ключа, измени `DEFAULT_USD_RUB` в `plugin.js` и перезагрузи плагин.

## Проверка перед установкой

Файл не требует сборки или npm-зависимостей. Проверка синтаксиса:

```bash
node --check plugin.js
```

Плагин использует только разрешённые импорты Hermes Desktop SDK, React и `react/jsx-runtime`.

## Ограничения

- OpenAI-лимиты зависят от доступности `session.usage` и авторизации Hermes.
- Значения Ollama Cloud обновляются вручную через `OLLAMA_USER_REPORT`.
- Для неизвестной модели тарифная оценка OpenAI не выполняется; в таком случае показывается `нет данных` для расчёта.
- Плагин не читает и не выводит токены, пароли или ключи.
